# Divine Dickson-Uwakwe — Portfolio

A responsive portfolio built with Next.js App Router, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Run `npm run lint` and `npm run build` before deployment.
